# finite-trace

Planned: the analogue of the local trace formula for a finite group of Lie type (starting with GL(2, F_q)).

Orbital integrals become class sums, the Plancherel measure becomes dim(π)²/|G|, the elliptic set becomes the elements in no proper parabolic subgroup, and everything can be computed exactly. Intended as an entry point to the p-adic case in `../local-trace/`.
