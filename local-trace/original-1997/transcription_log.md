# Errata log: "Simple local trace formulas for unramified p-adic groups" (D. Joyner, 10-97)

Prepared by Claude (Anthropic) for D. Joyner, 2026-11-10.
Companion to `local-trace-formula-transcription.tex` (the literal transcription) and the referee report `referee_report_ltf.pdf`.

The transcription reproduces the original exactly, errors included. This file records every problem found, so the revised, corrected and updated version can be produced from it later.

**Page numbers** refer to the original 35-page PDF. Equation and theorem numbers are the original ones; they are unchanged in the transcription.

**Tags:**
- **T**: typo or spelling
- **N**: notation or internal consistency
- **M**: mathematical error (the statement or formula as printed is wrong)
- **G**: gap (an argument is missing or incomplete)
- **B**: bibliography
- **R**: refers to item *n* in the referee report (e.g. R:M4 = report, Major issue M4)
