# original-1994

Reserved for the pre-revision source of *A hitch-hiker's guide to invariant
distributions on SL(2) over a p-adic field* (D. Joyner, notes dated
November 2, 1994).

Nothing has been added here yet. Two files belong in this directory:

- the 1994 notes themselves (scan or original source), if available;
- the Argon–Gemini LaTeX revision of those notes, which is the version the
  referee report in `../revised/` reviewed and which Draft 1 was rewritten
  from. Appendix B of Draft 1 describes it as a 2026 source snapshot, not a
  verified facsimile of the 1994 manuscript.
